# Smart Petrol Cost Calculator with BUDI MADANI Rebate

A modern, iOS-inspired Android mobile application designed to calculate estimated total petrol costs in Malaysia and apply the BUDI MADANI fuel subsidy to eligible users.

## 📱 Features
- **Petrol Type Selection:** Choose between RON95, RON97, or Diesel.
- **Dynamic Calculation:** Automatically calculates total cost based on price per liter and usage.
- **BUDI MADANI Integration:** Automatically applies the RM1.99/liter rebate strictly for eligible RON95 users.
- **Modern UI/UX:** Clean, responsive, and intuitive interface with a custom Material Toolbar and navigation.
- **About Page:** Contains complete author information and application details.

## 🛠️ Built With
- Java
- XML (Material Design Components)
- Android Studio
